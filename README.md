# 📚 Programação Orientada a Objetos

Este repositório reúne atividades, desafios e projetos desenvolvidos durante as aulas de **Programação Orientada a Objetos (POO) em Java**.

O objetivo é consolidar conceitos fundamentais da linguagem Java e aplicar boas práticas de desenvolvimento orientado a objetos.

---

## 🚀 Conteúdo do Repositório

Aqui você encontrará:

### 📦 Desafios práticos, Atividades acadêmicas e Projetos de estudo
- `Desafio1Interface.zip` → Exercício sobre Interfaces  
- `Desafio2.zip` → Segundo desafio em Java  
- `PrimeiraAtividade.zip` → Primeira atividade em Java  
- `TrabalhoPooN2.zip` → Atividade avaliativa  
- `ProjetoInterface.zip` → Introdução ao uso de Interfaces  
- `ProjetoN1.zip` → Projeto em grupo utilizando conceitos de POO  
- `ProjetoPolimorfismo.zip` → Aplicação de polimorfismo
